# projeto listagem de streamers 
Esse projeto será feito em REACT.
quero que use esse API "https://api.chess.com/pub/streamers" para atualizar a lista de streamers ao vivo .

## o projeto terá:
- O username do streamer
- O avatar do streamer ao lado do nome 
- Um pontinho verde indicando que aquele streamer está ao vivo  e quando estiver offline mostre um pontinho cinza 
- Terá a exibição da plataforma que o estreamer está fazendo a live .
- Terá também uma url direcionando para a plataforma que o streamer está fazendo a live

### EStrutura do projeto .

- usando React , quero que trabalhe com "UseState" e "UseEffects" 
- Quero uma lista dinâmica em React.
- Ultilize todas as pastas disponíveis e nessessárias que temos em nosso arquivo diponível
